# Installation / Installation en français

## English

### Android phones, tablets, and Android TV / Google TV

1. Install `Kaldora-Thor-Release.apk` from the [latest release](https://github.com/empy94/kaldora-thor/releases/latest) and pair your controller in Android settings.
2. Open **Kaldora Thor**. Android opens the game in your browser. If Android asks which app to use, select your browser. On TV, an installed browser must support Kaldora and the Gamepad API.
3. Sign in if requested, press a controller button with the game visible, and check **Settings → Controller** in the game. The browser and Android determine which controller inputs Kaldora can see.

### AYN Thor

1. On the AYN Thor, install Firefox for Android 142 or newer. Keep your existing Firefox profile to retain your game sign-in.
2. Download both files from the [latest release](https://github.com/empy94/kaldora-thor/releases/latest): `Kaldora-Thor-Release.apk` and the signed `Kaldora-Thor-Bridge-*.xpi` from that same release. Install the APK, allowing Android's installation prompt if needed.
3. In Firefox, open **Settings → About Firefox**, then tap the Firefox logo five times to reveal **Install extension from file** in Settings. This is a one-time setup.
4. Select the downloaded `.xpi` file and choose **Add**. Firefox shows the permissions needed to access Kaldora and transfer the game's chat and interface data to the companion on the same device. Private browsing access is optional.
5. Open **Kaldora Thor**, sign in if requested, and select your character. The game opens on the main screen and the companion on the second screen. The first eligible touch or key interaction can activate fullscreen; a joystick alone may not activate it.

The signed extension persists across Firefox and console restarts. Once installed, the local companion connection does not require a USB cable or a computer during play. The game itself requires an internet connection.

If the bottom screen is empty, verify that the extension is enabled in Firefox, then reopen Kaldora Thor. Do not clear Firefox data: that would remove its sign-in and game preferences.

### APK updates

From version 0.2.6, the launcher checks the latest stable GitHub release when opened, at most once every six hours after a successful check. Choose **Update** to download a newer APK, then approve installation in Android. The first update may require allowing installation from Kaldora Thor in Android settings. Choose **Later** to start the game. Install changes to the Firefox extension separately using the signed XPI.

## Français

### Téléphone, tablette et Android TV / Google TV

1. Installe `Kaldora-Thor-Release.apk` depuis la [dernière version](https://github.com/empy94/kaldora-thor/releases/latest) et associe ta manette dans les paramètres Android.
2. Ouvre **Kaldora Thor**. Android lance le jeu dans ton navigateur. Si Android te demande quelle application utiliser, sélectionne ton navigateur. Sur TV, le navigateur installé doit prendre en charge Kaldora et l’API Gamepad.
3. Connecte-toi si nécessaire, appuie sur une touche de la manette avec le jeu à l’écran, puis ouvre **Settings → Controller** dans le jeu. Les commandes disponibles dépendent de la reconnaissance de la manette par Android et le navigateur.

### AYN Thor

1. Installe Firefox pour Android version 142 ou ultérieure sur la Thor. Conserve ton profil Firefox actuel pour garder ta connexion au jeu.
2. Télécharge les deux fichiers depuis la [dernière version](https://github.com/empy94/kaldora-thor/releases/latest) : `Kaldora-Thor-Release.apk` et le fichier signé `Kaldora-Thor-Bridge-*.xpi` de cette même version. Installe l’APK et confirme l’installation demandée par Android si nécessaire.
3. Dans Firefox, ouvre **Paramètres → À propos de Firefox**, puis touche cinq fois le logo Firefox. L’option **Installer une extension depuis un fichier** apparaît dans les paramètres. Cette étape n’est à faire qu’une fois.
4. Sélectionne le fichier `.xpi` téléchargé puis touche **Ajouter**. Firefox présente les autorisations nécessaires pour accéder à Kaldora et transmettre les données du jeu et du chat au compagnon sur la même console. L’accès à la navigation privée est facultatif.
5. Ouvre **Kaldora Thor**, reconnecte-toi si nécessaire et sélectionne ton personnage. Le jeu s’ouvre sur l’écran principal et le compagnon sur le second. Un premier toucher ou une touche reconnue peut activer le plein écran ; le joystick seul ne suffit pas nécessairement.

L’extension signée reste installée après fermeture de Firefox et redémarrage de la console. Une fois installée, la liaison locale du compagnon ne nécessite ni câble USB ni ordinateur pour jouer. Le jeu nécessite une connexion Internet.

Si l’écran du bas reste vide, vérifie que l’extension est activée dans Firefox puis rouvre Kaldora Thor. Ne supprime pas les données de Firefox : cela effacerait sa connexion et les préférences du jeu.

### Mises à jour de l’APK

À partir de la version 0.2.6, le lanceur vérifie à l’ouverture la dernière release stable de GitHub, au maximum une fois toutes les six heures après une vérification réussie. Choisis **Update** pour télécharger le nouvel APK, puis confirme l’installation dans Android. Au premier lancement de l’installateur, Android peut demander d’autoriser l’installation depuis Kaldora Thor. Choisis **Later** pour lancer le jeu. Les mises à jour de l’extension Firefox s’installent séparément depuis le fichier XPI signé.
